# Homebrew tap for Basalt

```sh
brew install --cask navalm/tap/basalt
```

Basalt is a local-first personal finance app (alpha, Apple silicon). Releases are attached to this
repo; the cask in `Casks/basalt.rb` is generated by the release script. Alpha builds aren't signed
with an Apple Developer ID: allow the first launch in System Settings → Privacy & Security → Open
Anyway.
